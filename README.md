# Decision Tree

A decision tree is a flowchart-like visual structure or algorithm used to map out decisions and their possible consequences, functioning like an upside-down tree that splits into branches based on sequential rules.

This application provides an interactive and dynamic decision tree to navigate complex decisions and visualize the optimal path and series of decisions required to achieve a goal or some kind of growth.

Trees start off high-level, with nested nodes to depict specific actions and decisions someone can make with regards for the entire tree.
